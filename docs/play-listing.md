# Store listing copy

Ready to paste into the Play Console. Hebrew is the listing's default language, so that section
is the one that must be filled in; English is a second translation you add under
**Grow → Store presence → Main store listing → Manage translations**.

Character limits are Play's, and the counts below are the actual length of each string.

Every feature claimed here was checked against the code. Do not add claims for things that only
work on paper — the 13 presets, the widget, the reminder, the day overrides, calendar sync and
the editable shift names/colours/hours are all real; nothing here has been seen running on a
phone, which is a separate problem and not one the listing should paper over.

## Screenshots — still missing, and still blocking

Play requires **at least 2 phone screenshots** per listing language, and none exist, because the
app has never been run on a screen. They cannot be generated here.

When you install the debug APK:

1. Switch the app to Hebrew from its own settings, so the default listing's screenshots match
   the listing's language and read right to left.
2. Capture at least four: the month calendar with a rotation in it, the rotation setup screen,
   a day corrected by hand, and the homescreen widget in place.
3. Play accepts screenshots between 320px and 3840px on the short edge, 16:9 or 9:16.

Take the English set at the same time if you are adding the English listing — Play does not
reuse screenshots across languages by default.
